# Travel Budget Explorer

A static site to help users discover travel destinations based on their budget and departure date.

## Features
- Input your budget and departure date to find affordable destinations.
- Responsive design with Bootstrap.
- Mock data for testing (can be replaced with a real flight API).

## Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/fairyfemirins/travel-budget-explorer.git
   cd travel-budget-explorer
   ```

2. Open `index.html` in your browser or serve it locally:
   ```bash
   python3 -m http.server 8000
   ```
   Open [http://localhost:8000](http://localhost:8000) in your browser.
